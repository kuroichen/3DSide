# Stage1新設計

> **注記(2026-10-12)**: 中間地点(cp-01 / cp-02)は廃止した。復帰地点は「最後に入ったエリアの入口」で、Stage1Creatorはチェックポイント専用トリガーを作らない。以下のYAMLの `checkpoint` 行は旧設計として読み飛ばすこと。

[レベルデザイン法則集](../planning/レベルデザイン法則集.md)と

YAMLインタプリタは未実装のため、実装は従来どおり `Stage1Creator` (コード)で行うが、
**このYAMLが設計の正**であり、Creatorはこれを手で翻訳したものと位置づける。

## 旧設計からの変更点と理由

| # | 変更 | 理由(法則) |
|---|---|---|
| 1 | 丘を1.5m→3.0mに引き上げ、分岐入口をy3.5→y5.0へ | アンチパターン#1解消。踏切からの跳び上がり+2.0m(跳頂の60%)は維持 |
| 2 | 分岐入口の直下を「安全な窪地(pit)」に(道に穴・地面は残す) | 入口直下の頭上クリアランス4.55m確保(推奨4.2〜5.0)+分岐失敗の受け皿(法則B: 失敗即死させない) |
| 3 | ①穴あきの1つ目(2.0m)を安全穴に(落ちても草地に着地、登って復帰) | 法則D: 新ギミック(穴)は死なない環境で1回体験させてから本番(2.5m/3.0mの谷)へ |
| 4 | 隠し部屋入口(x70)の下に浮遊ブロックを配置 | 法則F: 視覚的な違和感で気づかせる。ブロック(y1.3)に乗れば頭上トリガー(y2.6)に届きやすい |
| 5 | 2段目・こぶ・3段目の高さを再構築(y5.0 / 7.0 / 9.4〜10.5) | 変更1の波及。こぶをy7.0にするのは3段目入口直下の2段目に3.6mのクリアランスを確保するため。ジャンプ要求(+2.0 / +2.4)は旧設計と同一 |
| 6 | Area2の分岐(丘・入口)にも同じ修正を適用 | 同上 |
| 7 | 穴・トリガーの位置指定をx座標→レール距離の変換で正確化 | 丘が高くなり弧長のズレ(最大1m超)が無視できなくなったため |

飛び降り一方通行の合流・Zレーン方式(z=7)・中間地点位置(58%)・裏ゴール・隠し部屋の構造は
法則と整合済みのため据え置き。コース(平面線形)は直線のまま
(カーブはカメラ符号の実機確認後、Stage2以降で導入)。

## 高さ・ジャンプ要求の検算

| 場面 | 要求 | 性能比(跳頂3.34m/飛距離4.5m) |
|---|---|---|
| 穴あき 2.0/2.5/3.0m | 前方跳び | 44〜67% ✓ |
| 踏切→2段目入口 | 前方3m・+2.0m | 67%・60% ✓(旧設計と同じ手応え) |
| こぶ→3段目入口 | 前方3m・+2.4m | 67%・72% ✓(裏ルート=高い技術要求。法則B) |
| 飛び石 登り+1.5m/穴3m | | 45%・67% ✓ |
| 隠し部屋トリガー(y2.6) | 素で78%、ヒントブロック(y1.3)経由なら39% ✓ |
| 2段目→合流の飛び降り | -4.7m | 落下ダメージ無しのため制約なし ✓ |

クリアランス検算(道の厚み0.8を差し引き):

- 分岐入口(y5.0)直下=窪地(地面y-0.35): **4.55m** ✓ 推奨帯(4.2〜5.0)
- 3段目入口(y9.4)直下=2段目の下り(y5.0): **3.6m** ✓ 最低ライン以上
- 2段目の合流端(y4.7)直下=ゴール前平地(y0): **3.9m** ✓ (旧設計は2.4mで違反していた)
- 2段目レーン(z=7)・3段目レーン(z=14〜18): 本筋(z=0)と直上関係なし ✓ (lane_z≧4)
