# ステージ作成パイプライン(エディタツール)

Splineを1本引けば遊べるステージになるまでの、エディタツール群の全体像。
すべて `Tools/Rail` メニュー配下にある。

## メニュー早見表

| メニュー | クラス | 役割 |
|---|---|---|
| Stage Spline Tool | `RailStageToolWindow` | Splineを「引く・分岐・連結」する補助ウィンドウ |
| Stage Auto Builder | `StageAutoBuilderWindow` | Splineから遊べるステージ一式を1クリック生成 |
| Create Default Theme | `ThemeSetupTool` | 既定テーマ「緑の丘」をKenney素材(CC0)から自動構築 |
| Create Demo Stage | `DemoStageCreator` | ツール動作確認用のデモステージ生成 |
| Create Stage 1 | `Stage1Creator` | 本番Stage1(2エリア構成の要素見本市)を自動生成 |
| Create Stage 2 | `Stage2Creator` | 本番Stage2(S字にうねる1本道+ゴールのみ)を自動生成 |
| Register Selected Scenes | `SceneRegistrationTool` | Projectで選択したシーンを開かずに共有Scene Listへ登録 |
| Scene List | `SceneListWindow` | 登録一覧を表示し、プロジェクト内のシーンを選んで追加、または開いているシーンを追加 |
| Audio/Create or Update Audio Mixer | `AudioMixerSetupTool` | 共通AudioMixerとAudioManager用設定アセット(AudioMixerSettings)を生成 |

## 生成の流れ(何が何を呼ぶか)

### 選択したシーンの登録

`Tools/Rail/Scene List` で専用ウィンドウを開く。上段は登録済みシーン一覧と有効・無効のチェック、下段は `Assets` 内の未登録シーン一覧とパス検索。「選択したシーンを追加」でチェックしたシーンを一括登録する。「開いているシーンを追加」は保存済みの開いているシーン（Additiveを含む）を登録する。未保存シーンは登録しない。既存のBuild Profiles側の操作もそのまま使用できる。

Projectウィンドウでシーンアセットを選択し、`Tools/Rail/Register Selected Scenes` を実行する。複数選択に対応し、シーン以外の選択は無視する。未登録シーンはパス順で末尾に追加し、既存シーンの順序は維持する。登録済みシーンは重複追加せず、無効なら有効化する。結果はConsoleに表示する。

登録先は `EditorBuildSettings.scenes` の共有Scene List。Build Profileで独自のScene Listを使用している場合は、そのリストにも登録するか共有Scene Listを使用する。シーンを開いたり、現在のシーンを保存したりする必要はない。

```
① Splineを引く         Stage Spline Tool(またはCreatorが自前で引く)
② ステージ化           Stage Auto Builder
    ├ SplineRail化 + RailManager等のマネージャ配置
    ├ 道ジオメトリ生成   → StageGeometryUtility
    ├ スポーン地点(SplineAnchor)
    ├ StageView / Camera生成(カメラはステージSceneの確認用。実行時はStageLoaderが無効化)
    └ 敵・アイテム配置(PlacementEntry)
③ 見た目の適用         StageDecorator(StageThemeを読む)
    ├ 道端に飾りを散布(草・岩・木)
    ├ 遠景生成(丘・山・谷底)
    └ 空・フォグ・太陽光・ポストプロセス適用
```

- `Stage1Creator` のような「Creator」は、この①〜③をコードから順に呼ぶ**レシピ**。手作業の代わりに再現可能な手順として残している
- プレイヤー関連は生成しない。Player Prefabは `StageLifetimeScope` から `PlayerFactory` へ渡し、`StagePresenter` が生成ライフサイクルを所有する
- `Stage1Creator` の保存先は `Assets/Scenes/World1_Stage1.unity`、`Stage2Creator` は `Assets/Scenes/World1_Stage2.unity`。実ステージのシーン名は `StageLoader` の `{WorldId}_{StageId}` に揃える。シーン名変更時は `.meta` も一緒に移動してGUIDを維持する。
- Creatorは全エリアと全イベントトリガーを`StageView`(`areas` / `areaTriggers`)へ、初期エリアと`StageView`を`StageDefinition`へ明示的に配線する(`WireStageView`)。`StageView`がエリア操作とトリガー集約の唯一の窓口で、`StageDefinition`はシーンの入口(初期エリアとViewの在り処)だけを持つ。各`StageArea`にはステージ開始時の開始地点を配線し、エリア遷移時の出現地点は`AreaTransitionInfo.destinationPoint`に配線する(入口ごとに出現位置が変わるため)。
- 敵はシーンに実体を置かず、出現地点(`SplineAnchor` + `EnemySpawnPoint`)だけを置いて各`StageArea.enemySpawnPoints`へ配線する(`CreateEnemySpawnPoint`)。実体は実行時に`StageView.ResetEnemies`→`StageArea`が`EnemyFactory`経由で`contentsRoot`配下に生成するため、エリアのON/OFFに追従し、リスポーン時は消して出し直すだけで初期状態に戻る。※`StageAutoBuilderWindow`の汎用配置(PlacementEntry)はまだプレハブを直置きする。
- Stage Auto Builderには**スクリプト連携用の外部指定API**があり(メインSpline指定、道生成ON/OFF等)、Creatorが穴あき道など特殊な道を自前で敷きたい場合は道生成だけOFFにできる

## StageGeometryUtility — 道と大地の生成

Splineから4種類のジオメトリを作れる共通部品(コライダー付き):

| 生成物 | 用途 |
|---|---|
| 道メッシュ | Splineに沿った平らな道 |
| キューブ敷き | ブロックアウト(検証用の仮地形)向け |
| 地面リボン | 道の下に広がる幅広の大地(幅60m) |
| 崖壁 | 地面の外縁と谷の断面に張る垂直の壁 |

- **holeRanges**: レール距離(railZ)の範囲指定で道に穴を開けられる(飛び石・谷)。地面リボンは穴を道より広めに裂いて「谷」に見せる(`groundHolePadding`)
- 生成物は壁ずり判定(CapsuleCast)が効くよう**Terrainレイヤー**に載せる

## StageTheme — 見た目のデータ化

テーマ(ScriptableObject、`Rail/Stage Theme` で作成)に見た目を全部持たせ、
ジオメトリ(形)と分離している。同じステージにテーマだけ差し替えができる。

- **道・地面・崖のマテリアル**、**遠景**(山にする巨大化モデル、丘/山/谷底の色)、**空・フォグ・太陽光**
- **散布設定(ScatterEntry)**: 何を(prefab候補からランダム)、どれくらい(10mあたり個数)、どこに(レール中心からの横距離帯 2.1〜2.8m = プレイヤー可動域±2mの外)置くか
  - `ScatterSide.FarSide` = カメラの奥側だけに置く。背の高い木で手前の視界を塞がないため
  - `targetHeight` 指定でモデルの実寸を測って正規化 → アセットパックごとの元サイズ差に影響されない
  - **乱数はテーマのシードで固定** → 再生成しても同じ配置(差分が出ない)
- テーマ構築ツールは2つ: `ThemeSetupTool`(緑の丘) / `FantasyThemeSetupTool`(FantasyForest素材)

## 設計思想

1. **シーンを手で編集しない**。ステージはCreator(コード)で再生成可能にする → 壊れたらもう一度実行すればよい。ジャンプ性能を変えたら本番ステージで実測→Creatorの数値を直して再生成、が回せる
2. **形(Geometry)と見た目(Theme)と配置(Builder)を分離** → テーマ差し替え・ステージ量産に耐える
3. 座標指定は**レール距離(m)ベース**。Splineのtは使わない([learning/03参照](../learning/03_UnitySplinesの使い方.md))
