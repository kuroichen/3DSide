# カメラ追従の仕組み

`SplineFollowCamera` の解説。横スクロールの「常に横から見る」をレールが曲がっても維持する。

## 核心: オフセットを「レールの横方向」に取る

固定オフセット(ワールドZ方向など)だと、道がカーブした瞬間に正面や背後からのアングルになってしまう。
そこで**プレイヤーが今いる場所のレール接線に対して垂直な方向**へカメラを置く:

```csharp
var tangent = this.targetMover.Tangent;                 // レールの進行方向
var right = Vector3.Cross(Vector3.up, tangent).normalized;  // 上×接線 = 横方向

var targetPosition = player.position
    + right * offset.z      // レールの横へ離れる(カメラ距離)
    + Vector3.up * offset.y; // 高さ
this.transform.LookAt(player.position);
```

道がどう曲がっても `right` が一緒に回るので、画面上は常に「左右に走る横スクロール」に見える。
**外積 `Cross(up, tangent)` で横ベクトルを得る**のはレール系全体で使う基本イディオム。

## 振り向きでカメラも回り込む

プレイヤーが逆方向を向いたら、カメラは反対側から映す(進行方向が常に画面の同じ側になる):

- `SplineMover.OnSplineDirectionChanged`(接線のx符号で右向きか判定)を購読
- 右向きなら `offset.z` を正、左向きなら負に反転するだけ

移動はLerp補間(`positionSmooth`)なので、反転時は回り込みの弧を描いた自然な移動になる。

## 細かい作法

- **LateUpdateで動かす**。プレイヤーのUpdate(移動)が終わった後の位置を映さないと、1フレーム遅れの震えが出る
- 追従対象はリスポーンで作り直されるため、`PlayerManager.Spawn` が毎回 `SetTarget` で繋ぎ直す
- `Vector3.Lerp(current, target, smooth * deltaTime)` の指数追従なので、距離が離れるほど速く追う(急な移動でも置いていかれない)
