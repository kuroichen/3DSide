# ノックバックの仕組み

「吹き飛ばす」は普通のゲームなら `Rigidbody.AddForce` 一発だが、
このプロジェクトは**水平移動がレール駆動**なので、ワールド空間の衝撃をレール空間に翻訳する必要がある。
その翻訳が `CharacterMover.AddImpulse` の仕事。

## 全体の流れ

```
被弾: TakeDamage(DamageInfo)
  ① ノックバックベクトルを計算(ワールド空間)
  ② AddImpulse(ベクトル) … ワールド→レール空間への翻訳
  ③ Damageステートへ(一定時間、入力や攻撃を制限)
  ④ 毎フレーム外力が減衰しながらrailZ/垂直速度に効き続ける
```

## ① 方向の計算 — attackerから離れる向き

```csharp
var direction = this.transform.position - damageInfo.attacker.position;
direction.y = 0.0f;  // 水平成分だけ使う
return direction.normalized * knockbackForce + Vector3.up * knockbackUpForce;
```

- `DamageInfo.attacker`(Transform)を渡しているのはこのため。「攻撃者の反対側へ水平に + 少し上に」が基本形
- 水平と垂直を別パラメータ(`knockbackForce` 2.5 / `knockbackUpForce` 3.0)にしているので、「浮かせ気味」「押し出し気味」を独立に調整できる

## ② AddImpulse — ワールド→レール空間の翻訳(核心)

レール上では自由なXZ移動が存在しないので、衝撃を2成分に分解する:

```csharp
public void AddImpulse(Vector3 worldImpulse)
{
    // XZ成分: レール接線との内積 → 「レールに沿ってどれだけ押されたか」
    var tangentXZ = new Vector3(Tangent.x, 0, Tangent.z).normalized;
    var dot = Vector3.Dot(worldImpulse, tangentXZ);
    this.impulseVelocityT += dot / Mathf.Max(0.001f, this.Speed);

    // Y成分: 重力系の垂直速度に直接加算
    this.verticalVelocity += worldImpulse.y;

    // 外力による上昇は可変ジャンプの減衰対象にしない
    this.canCutJump = false;
}
```

3つのポイント:

1. **内積で「レール方向の成分」だけ取り出す** — 正なら進行方向へ、負なら逆方向へ押される。レールと直交する衝撃は自然に無視される(横に吹き飛んでレールから外れることはない)
2. **`Speed` で割る** — `impulseVelocityT` は「入力と同じ単位」(SplineMover側で `× Speed` されるため)。つまり外力は「仮想の移動入力」としてrailZに合流する:
   ```csharp
   // SplineMover.Update
   var totalInput = input + this.impulseVelocityT;
   this.railZ += totalInput * this.Speed * Time.deltaTime;
   ```
3. **`canCutJump = false`** — ノックバックの上昇中にプレイヤーがジャンプボタンを離しても、可変ジャンプの減衰(×0.4)が掛からないようにする。外力とジャンプは別物

## ④ 減衰 — 摩擦の代わり

```csharp
// SplineMover.Update(毎フレーム)
this.impulseVelocityT = Mathf.Lerp(this.impulseVelocityT, 0f, this.impulseDecay * Time.deltaTime);
```

- 水平の外力は `impulseDecay`(10)の指数減衰でスーッと止まる。物理エンジンの摩擦の代替
- 垂直成分は通常の重力処理がそのまま面倒を見る(上昇→減速→落下→着地)

## ③ ステート側の役割 — 「操作できない時間」

ノックバックの物理(上記)とは独立に、ステートマシンが行動制限を担当する:

| | Player | Enemy |
|---|---|---|
| 被弾時 | `PlayerState.Damage` へ | `EnemyState.Damage` へ |
| 制限内容 | 攻撃入力を受けない(移動は可) | `GetInput()` が0を返す=自力移動停止 |
| 復帰 | `knockbackTimer`(0.3秒)経過で `Move` へ | 同じく経過で `Patrol` へ |

- **物理(AddImpulse)とステート(Damage)を分離**しているのが設計の要。「吹き飛ばすが操作は奪わない」(強風ギミック等)や「怯むが吹き飛ばない」(スーパーアーマー)のような組み合わせが将来作れる
- タイマー中も `base.Update()` は呼び続ける。外力の減衰・重力・着地は動き続けるので、空中で被弾しても自然に落ちる

## 調整パラメータまとめ

| 触りたいもの | 場所 | パラメータ |
|---|---|---|
| 吹き飛ぶ距離 | PlayerCharacter / EnemyCharacter | `knockbackForce` |
| 浮き上がり | 同上 | `knockbackUpForce` |
| 操作不能時間 | 同上 | `knockbackDuration` |
| 滑る長さ(減衰) | SplineMover | `impulseDecay`(大きいほどすぐ止まる) |

## 既知の注意点

- 無敵時間が未実装なので、連続ヒットでノックバックが連鎖し得る(ロードマップPhase 4で対応予定)
- `impulseVelocityT` は `Speed` 依存なので、移動速度の遅いキャラほど同じ衝撃で長く押される(現状は許容)
