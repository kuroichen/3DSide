# コーディングスタイル

> **ドラフト**: 既存コード(PlayerController、AudioManager、StageFlowManagerなど)から抽出した現状のスタイル。合意したら確定版にする。

## 命名

- クラス・メソッド・プロパティ: `PascalCase`
- フィールド・ローカル変数: `camelCase`(プレフィックスなし。`_` や `m_` は使わない)
- 定数: `UPPER_SNAKE_CASE`(`const float DEFAULT_FADE_DURATION = 0.5f;`)
- インターフェース: `I` プレフィックス(`IRail`、`IDamageable`、`ILife`)
- Manager系の接尾辞ルールは [命名規約.md](命名規約.md) を参照

## クラス構成

- namespaceは `Rail` に統一
- インスタンスメンバーへのアクセスは `this.` を明示する
- フィールドは `[SerializeField]` + private(publicフィールドは作らない)。参照型は `= null` で初期化
- 公開APIには `/// <summary>` XMLドキュメントコメント。コメントは日本語で「なぜそうなっているか」を書く
- 状態機械は `enum` + `Update` 内の `switch` + `ChangeState` メソッドのパターン
- 常駐サービスはRootLifetimeScopeプレハブに置き、DIで受け取る(シングルトンにしない)。`SingletonMonoBehaviour<T>` は移行前の旧クラス(PlayerManager、RailManager)にのみ残っている
- `#region` でステートやカテゴリごとにグルーピング

## UniRx

- イベント公開は `IObservable<T> OnXxxObservable()` メソッド形式(Subjectを直接publicにしない)
- Subjectフィールドは `onXxxSubject` という命名
- 購読は必ず `.AddTo(this)` または `CompositeDisposable` で寿命管理
- デバッグ用のログは `.Do(x => Debug.Log(...))` でパイプラインに挟む

## UniTask

- 非同期メソッドは `Async` 接尾辞。fire-and-forgetは `UniTaskVoid` + `.Forget()`
- キャンセルは `GetCancellationTokenOnDestroy()` とリンクした `CancellationTokenSource` で管理
- ポーズ中も動かす処理(フェードなど)は `Time.unscaledDeltaTime` を使う

## ログ

- `Debug.Log($"[ClassName]メッセージ")` の形式でクラス名プレフィックスを付ける
- (Phase 6でConditional属性のロガーにラップ予定 → [ロードマップ.md](../planning/ロードマップ.md))

## フォルダ

- ランタイムスクリプトは `Assets/Scripts/<機能名>/`
- エディタ拡張は `Assets/Scripts/Editor/`
- サードパーティは `Assets/ThirdParty/` または `Assets/Plugins/`
