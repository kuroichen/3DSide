# ロードマップ — 基本的なゲームとして完成させる

2026-07-25の全体レビューより。「まず1ステージが最初から最後まで遊べる」を最優先に、依存関係順で並べる。
(2026-10-13 更新: VContainer + MVP移行の完了を反映)

## 現状の要約

遊べるメカニクス(移動・ジャンプ・攻撃・被弾・リスポーン・エリア遷移)と、Start→Title→World→Stageのシーン遷移、ステージHUD(HP・残機)はある。ゲームとして成立させる外枠(クリア/ゲームオーバー・音・セーブ・ポーズ)が未着手。

構成はVContainer + MVP(Presenter / Model / EventBus)に移行済み。旧 `StageFlowManager` / `PlayerManager` は削除した([ステージ進行の仕組み](../knowledge/ステージ進行の仕組み.md))。

### 判明している実質バグ

- **ゲームオーバーで詰む**: `PlayerEventBus.OnLivesDepletedObservable()` の購読者がゼロ。残機切れ時に暗転したままソフトロックする
- **ゴールしても何も起きない**: `StagePresenter.HandleAreaEvent` が `GoalInfo` / `StageExitInfo` を処理しない。`Secret`/`Fake` のGoalTypeも未使用
- **敵の死亡処理が空**: `EnemyCharacter.UpdateDead` が空実装で、倒した敵が消えない
- **AudioManagerの呼び出し箇所ゼロ**: 基盤はあるがBGM・SEが一切鳴らない
- **エリア遷移で暗転しない**: 旧StageFlowManagerにあった暗転が未移植(StagePresenterで「FadeOut→ChangeArea→FadeIn」を入れる予定)

## Phase 1: ゲームループを閉じる 🎯

ここが終わると初めて「ゲーム」になる。

1. **GameFlowManagerの新設** — タイトル→ステージ→リザルト→タイトルのシーン遷移を統括。ScreenTransitionを流用。RootLifetimeScope常駐組(残機の持ち越しもここで決める)
2. **ゴール処理の実装** — `StagePresenter.HandleAreaEvent` で `GoalInfo` を受けてクリア演出→リザルト表示→遷移。Secret/Fakeの挙動もここで定義
3. **ゲームオーバー処理の実装** — `PlayerEventBus.OnLivesDepletedObservable` を購読し、GameOver画面→リトライ/タイトルへ
4. ~~最小限のタイトルシーンとBuild Settings整備~~ — 済(Start/Title/World/Stageシーンを登録済み)

## Phase 2: ポーズと設定

1. ポーズメニュー(`Time.timeScale = 0`、再開/リトライ/タイトルへ)。ScreenTransitionのunscaledDeltaTime対応確認込み
2. オプション画面(音量スライダー → `AudioManager.SetVolume`)
3. `PlayerPrefs` による設定の保存・復元(RootLifetimeScopeの常駐サービスで読み込み)

## Phase 3: サウンド接続

1. ステージ/エリアごとのBGM再生(`StageDefinition` にBGM参照を持たせ、StagePresenterから `PlayBGM`)
2. SEフック — ジャンプ・攻撃・被弾・死亡・アイテム取得・エリア遷移・UI操作
3. 音源アセットの調達と整理(Mixer設定はRootLifetimeScopeのAudioManagerにInspectorで配線する。`Resources.Load` は使わない)

## Phase 4: 戦闘の手触り

1. 被弾後の無敵時間+点滅(`PlayerModel.Damage` が無敵中は `DamageResult.Ignored` を返す形で入れられる)
2. 敵の死亡処理(死亡アニメ→消滅、`UpdateDead` の実装)
3. ヒットエフェクト・ヒットストップ
4. 敵バリエーション追加(攻撃してくる敵、飛行する敵など)。敵のスポーンはSpawner方式(`EnemySpawnPoint`)で実装済み。差し替えを楽にするなら種類/定義アセット化を検討

## Phase 5: コンテンツ拡張

1. コイン/スコアシステム(リザルトと連動)。アイテムは `ItemEffectType` を足して `PlayerPresenter.ApplyItem` で振り分ける。配置はアイテム用のSpawnerを作る
2. ギミック追加 — 動く床、トゲ、跳ね台
3. Stage2以降の追加(既存のステージ生成ツールを活用)
4. ステージクリア進行度のセーブとステージ選択画面

## Phase 6: 磨き

1. Debug.Logの整理(Conditional属性のロガーでラップ)
2. タイトル・リザルトの演出強化、カメラ演出
3. プレイテストとバランス調整
