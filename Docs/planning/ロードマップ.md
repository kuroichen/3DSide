# ロードマップ — 基本的なゲームとして完成させる

2026-07-25の全体レビューより。「まず1ステージが最初から最後まで遊べる」を最優先に、依存関係順で並べる。

## 現状の要約

遊べるメカニクス(移動・ジャンプ・攻撃・被弾・リスポーン・エリア遷移)はあるが、ゲームとして成立させる外枠(ゲームループ・音・セーブ・ポーズ)がほぼ未着手。

### 判明している実質バグ

- **ゲームオーバーで詰む**: `PlayerManager.OnGameOverObservable()` の購読者がゼロ。残機切れ時に操作不能のままソフトロックする
- **ゴールしても何も起きない**: `StageFlowManager.HandleGoal` がDebug.Logのみ。`Secret`/`Fake` のGoalTypeも未使用
- **Build SettingsにSampleSceneしか登録されていない**(Stage1すら未登録)
- **敵の死亡処理が空**: `EnemyCharacter.UpdateDead` が空実装で、倒した敵が消えない
- **AudioManagerの呼び出し箇所ゼロ**: 基盤はあるがBGM・SEが一切鳴らない

## Phase 1: ゲームループを閉じる 🎯

ここが終わると初めて「ゲーム」になる。

1. **GameFlowManagerの新設** — タイトル→ステージ→リザルト→タイトルのシーン遷移を統括。ScreenTransitionを流用。RootLifetimeScope常駐組
2. **ゴール処理の実装** — `HandleGoal` からクリア演出→リザルト表示→遷移。Secret/Fakeの挙動もここで定義
3. **ゲームオーバー処理の実装** — `OnGameOverObservable` を購読し、GameOver画面→リトライ/タイトルへ
4. **最小限のタイトルシーン**(スタートのみ)と **Build Settings整備**

## Phase 2: ポーズと設定

1. ポーズメニュー(`Time.timeScale = 0`、再開/リトライ/タイトルへ)。ScreenTransitionのunscaledDeltaTime対応確認込み
2. オプション画面(音量スライダー → `AudioManager.SetVolume`)
3. `PlayerPrefs` による設定の保存・復元(RootLifetimeScopeの常駐サービスで読み込み)

## Phase 3: サウンド接続

1. ステージ/エリアごとのBGM再生(`StageDefinition` にBGM参照を持たせ、StageFlowManagerから `PlayBGM`)
2. SEフック — ジャンプ・攻撃・被弾・死亡・アイテム取得・チェックポイント・UI操作
3. 音源アセットの調達と `Resources/Audio` への整理

## Phase 4: 戦闘の手触り

1. 被弾後の無敵時間+点滅(PlayerState.Damageの拡張)
2. 敵の死亡処理(死亡アニメ→消滅、`UpdateDead` の実装)
3. ヒットエフェクト・ヒットストップ
4. 敵バリエーション追加(攻撃してくる敵、飛行する敵など)+スポーン管理

## Phase 5: コンテンツ拡張

1. コイン/スコアシステム(リザルトと連動)
2. ギミック追加 — 動く床、トゲ、跳ね台
3. Stage2以降の追加(既存のステージ生成ツールを活用)
4. ステージクリア進行度のセーブとステージ選択画面

## Phase 6: 磨き

1. Debug.Logの整理(Conditional属性のロガーでラップ)
2. タイトル・リザルトの演出強化、カメラ演出
3. プレイテストとバランス調整
